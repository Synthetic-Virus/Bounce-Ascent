WINDOWS DEFENDER WARNING - QUICK FIX
=====================================

When you run BounceAscent.exe, Windows may show a warning:
"Windows protected your PC" or "Unknown publisher"

THIS IS NORMAL AND SAFE!

The warning appears because:
- The game is not digitally signed (signing costs $400+/year)
- Windows doesn't recognize it yet
- It's a new file from the internet

HOW TO RUN THE GAME:
====================

1. Double-click BounceAscent.exe
2. When warning appears, click "More info"
3. Click "Run anyway"
4. Game starts! ✓

The warning won't appear again for this file.
