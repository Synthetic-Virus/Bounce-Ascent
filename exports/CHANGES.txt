BOUNCE ASCENT - VERSION 1.1
=============================

Updated: October 7, 2025

NEW FEATURES:
=============

1. PROFILE EDITOR
   - Access via "PROFILE" button on main menu
   - Customize your player name (up to 20 characters)
   - Choose from 8 ball colors:
     * Neon Blue (default)
     * Red
     * Green
     * Yellow
     * Purple
     * Orange
     * Cyan
     * Pink
   - View comprehensive statistics:
     * High Score
     * Total Runs
     * Total Height
     * Platforms Landed/Broken
     * Total Time Survived
     * Deaths and Rage Quits

2. COUNTDOWN SYSTEM
   - 3-second countdown before gameplay starts
   - Shows: 3... 2... 1... GO!
   - Platforms spawn during countdown
   - Gives you time to prepare!

3. IMPROVED MAIN MENU
   - New "PROFILE" button
   - Cleaner display: Shows only Player Name and High Score
   - Total runs moved to Profile Editor

FIXES:
======

- Fixed game immediately going to game over screen
- Fixed game over screen not showing session stats
- Player name now defaults to "Player" if not set
- Ball color persists between game sessions
- Improved game initialization sequence

HOW TO USE:
===========

MAIN MENU:
  - PLAY: Start a new game
  - PROFILE: Customize name, ball color, view stats
  - QUIT: Exit game

PROFILE EDITOR:
  - Type your name in the text box
  - Click a color swatch to change ball color
  - Yellow border shows current selection
  - CLOSE button to return to menu

GAMEPLAY:
  - Wait for countdown: 3... 2... 1... GO!
  - Game starts after countdown
  - Arrow Keys/WASD: Move left/right
  - Spacebar: Force jump
  - ESC: Quit to desktop

SAVE FILE:
==========

Location: C:\Users\YOUR_USERNAME\AppData\Roaming\Godot\app_userdata\Bounce Ascent\
