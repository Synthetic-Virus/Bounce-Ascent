# Contributing

Short version: **this project is not accepting contributions.**

Bounce Ascent is a personal project. It is public so the code is readable and so
the builds on the [releases page](../../releases) can be downloaded without an
account, not because it is looking for collaborators.

## Pull requests

Pull requests will not be reviewed or merged, including small ones. Please do
not spend your time on a patch here.

## Issues

The issue tracker is the author's own planning board. Bug reports on a release
build are genuinely useful and welcome; feature proposals and roadmap
suggestions are not, because the direction is already decided.

If you do report a bug, the useful details are the release version, your OS, and
what you did immediately before it happened. Timing complaints should say
whether you had run **Calibrate audio** first, since uncalibrated output latency
is wider than the whole PERFECT window and looks exactly like a bug.

## Forking

The MIT license permits forking, modifying and redistributing this code, and
that permission is genuine. It is simply separate from the question of whether
changes come back upstream. Build whatever you like from it; just do not expect
it to be merged here.
